# Deploy IMovies for a demo

This repository is configured for a single Render web service. It serves the React frontend and Express API from one `onrender.com` URL. The Blueprint is in [`render.yaml`](render.yaml).

## One-time setup

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Create a MongoDB Atlas free cluster and a database user. Add a network access rule that allows Render to connect. Render's free services do not provide a fixed outbound IP, so Atlas may require a broad IP rule; use a unique, strong database password and restrict access again when the demo is over. Atlas explains the implications of `0.0.0.0/0` in its [IP access list documentation](https://www.mongodb.com/docs/atlas/security/ip-access-list/).
3. Copy the Atlas application's connection string. Replace its password placeholder and include the database name `imovies`.
4. In Render, choose **New → Blueprint**, connect the repository, and select the branch to deploy. Render will read `render.yaml` and prompt for `MONGODB_URI`; paste the Atlas connection string there.
5. Wait for the build and deploy to finish. Open the service URL and check `/api/health` if you want to confirm the backend is responding.

The server seeds demo movies, theatres, shows, and accounts when the Atlas database is empty. Demo accounts are listed in the project README. Avoid entering real personal or payment information in this demo.

## Demo notes

- Render's free web services sleep after 15 minutes without traffic and can take about a minute to wake. This is expected for a free demo. [Render free service details](https://render.com/docs/free).
- Atlas free clusters have limited capacity and can pause after 30 days without connections. [Atlas free cluster limits](https://www.mongodb.com/docs/atlas/reference/free-shared-limitations/).
- Uploaded files are stored on the web service's local filesystem, which is temporary on Render's free plan. Use the seeded remote movie images for the presentation; uploaded files may disappear after a restart or deploy.
- Keep `.env` files and database credentials out of Git. `JWT_SECRET` is generated by Render from the Blueprint.
